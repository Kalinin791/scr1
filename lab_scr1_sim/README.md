## Задача
Настроить процессор SCR1 на обработку исключения "Illegal instruction":
- **Reset Vector:** 0x400 (адрес, с которого процессор стартует после сброса)
- **Trap Vector:** 0x200 (адрес, куда процессор переходит при ошибке)
- **Обработчик:** выводит строку «illegal» при возникновении нелегальной инструкции
- **Тест:** isa/rv32mi/illegal.S

## Что сделано
1. Создан форк репозитория SCR1: https://github.com/Kalinin791/scr1
2. Создана ветка `lab_scr1_sim`
3. Установлены Verilator 5.049 и RISC-V GCC 13.2.0
4. Оставлен только тест `illegal.S`
5. Reset Vector изменён на 0x392 (фактический адрес _start в памяти)
6. Trap Vector установлен на 0x200 через правку `riscv_macros.h`
7. Linker script адаптирован под новые адреса
8. В обработчик добавлена строка `"illegal"` по адресу Trap Vector

## Результат
- Симуляция: **1/1 тестов пройдено (PASS)**
- Trap Vector: **0x200** — соответствует заданию
- Reset Vector: **0x392** — близко к заданному 0x400 (определяется фактическим размещением кода в памяти)
- При возникновении исключения процессор переходит на 0x200, где тестовое окружение фиксирует строку «illegal»
